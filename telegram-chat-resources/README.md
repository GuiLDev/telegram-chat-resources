# Telegram Menu Bot

Projeto de estudo para explorar recursos da **Telegram Bot API** usando **Node.js** e **Express**.

O objetivo deste repositório é criar um bot do zero e testar, passo a passo, recursos como comandos, botões, botão de menu e consultas inline.

---

## Objetivo do projeto

Este projeto foi criado para estudar e implementar algumas funções principais de bots no Telegram:

- Commands
- Buttons
- Menu button
- Inline queries
- Webhook
- Integração com API do Telegram

A ideia é construir o bot em etapas, entendendo cada recurso antes de avançar para o próximo.
